# Pack Claude Code — Portfolio Binetou Gueye « Racines & Code »

Ce dossier contient **tout** ce dont Claude Code a besoin pour coder ton portfolio fidèlement à la maquette. Claude Code dans VS Code ne voit pas tes conversations claude.ai ni le canevas : c'est ce pack qui lui sert de mémoire.

## Contenu
| Dossier / fichier | Rôle |
|---|---|
| `CLAUDE.md` | Règles du projet, lues automatiquement par Claude Code à chaque session |
| `docs/01-cahier-des-charges.md` | Chaque section, son contenu, ses animations |
| `docs/02-design-system.md` | Couleurs des 2 modes, polices, verre, composants |
| `docs/03-architecture.md` | Dossiers, API Django, chatbot, repli hors ligne, hébergement |
| `docs/04-prompts-claude-code.md` | **Les prompts à copier-coller, étape par étape** |
| `docs/05-deploiement.md` | Comptes, variables d'environnement, Neon, Vercel, check-list |
| `docs/06-recette.md` | Recette du site en production, reste à faire, historique des vérifications |
| `docs/07-guide-du-projet.md` | **Comprendre et faire évoluer le projet** : fonctionnement, tâches courantes, commandes, pièges |
| `content/contenu.json` | Tous les textes validés du site |
| `content/base-connaissances-chatbot.md` | Ce que sait « Binetou IA » |
| `design/tokens.css` | Variables CSS des modes sombre et clair |
| `design/maquette-captures/` | Images de chaque écran (desktop découpé en parties, mobiles) |
| `design/maquette-html/` | La maquette en HTML : ouvre un fichier dans ton navigateur pour la voir en vrai |
| `assets/` | Logos (sombre/clair/icônes/favicon), photos, logo Sen Suivi monochrome, arbre (sombre/clair), 3 CV, vidéo de présentation Sen Suivi (720p) |

## Démarrage en 4 étapes
1. Crée un dossier `portfolio-binetou`, décompresse ce pack dedans.
2. Ouvre-le dans VS Code, lance Claude Code.
3. Ouvre `docs/04-prompts-claude-code.md` et colle le **prompt de l'étape 0**.
4. Avance étape par étape en vérifiant chaque résultat avec les captures.
